Frequently asked questions

Is NarrateX free?

Yes. NarrateX is free and open source, released under the GNU GPL-3.0 licence with the reusable UI layer under LGPL-3.0.

Does NarrateX work offline?

Yes. NarrateX runs entirely on your device with no cloud dependency. Nothing you read is uploaded anywhere. Beyond the one-off voice-model download, its only recurring network request is a daily check of the project's GitHub releases for a newer version; it carries nothing about you and fails silently without a connection.

What does the narration sound like?

NarrateX uses the Kokoro neural text-to-speech voice running on your own machine, which is a long way from the robotic voices people remember. It is not as natural as the large cloud services; in exchange nothing you read leaves your computer, it works with no internet at all and there is no per-word cost or usage cap.

Can I choose the voice?

Yes. NarrateX ships Kokoro's complete English inventory of 28 voices (8 British and 20 American), filtered by sex and region toggles, all running on-device.

Which file formats can NarrateX read?

EPUB, PDF, plain text and Markdown.

Which platforms does NarrateX run on?

Windows, macOS and Linux, shipped as an installer, a disk image (.dmg) and a Flatpak respectively.
